# Ứng Dụng Quản Trị Sản Phẩm Đa Nền Tảng (React Native Expo + Firebase)

Dự án bài tập lớn xây dựng hệ thống Admin quản lý sản phẩm đa nền tảng (Web & Mobile), kết nối Firebase Authentication, Cloud Firestore và Firebase Storage.

---

## 🚀 Hướng Dẫn Chạy Nhanh

### 1. Cài đặt thư viện
```bash
npm install
```

### 2. Kiểm thử mã nguồn (TDD Unit Tests)
```bash
npm test
```

### 3. Chạy trên Web (Trình duyệt) - Tiêu chí 8.0 Điểm
```bash
npm run web
```
Mở trình duyệt truy cập: `http://localhost:8081`

### 4. Chạy trên Di Động (Expo Go) - Tiêu chí 0.5 Điểm
```bash
npx expo start
```
Mở app **Expo Go** trên điện thoại Android/iOS và quét mã QR hiển thị trên màn hình.
